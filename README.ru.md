# YouTubeToDiscord

[English version](README.md)

Discord Rich Presence для YouTube и YouTube Music. Показывает в **десктопном Discord**, что ты сейчас смотришь или слушаешь на **YouTube** и **YouTube Music** (в Chrome или другом Chromium-браузере), в виде Rich Presence статуса.

## Возможности

- Статус «Слушает YouTube» с названием видео / трека и каналом / исполнителем
- Живой прогресс-бар: сколько проиграно и сколько всего, корректно обновляется при перемотке
- Большая картинка: превью видео (обложка альбома на YouTube Music)
- Маленькая картинка: аватарка канала (только на YouTube)
- Определение паузы: таймер пропадает, рядом с автором появляется ⏸
- Кликабельные название, автор, превью и аватарка (ведут на ролик или канал)
- Две кнопки для других пользователей: **Open video** и **Open channel**
- Работает скрыто в фоне, с иконкой в трее и пунктом **Exit**
- Статус убирается автоматически, когда ты закрываешь вкладку или останавливаешь воспроизведение

## Как это работает

Скрипт в браузере не может напрямую общаться с Discord, потому что Discord слушает только локальный IPC-канал. Поэтому проект состоит из двух частей:

```
Chrome (userscript в Tampermonkey)  ──HTTP──►  локальный мост (Node.js)  ──IPC──►  десктопный Discord
 читает название, время, превью…              127.0.0.1:6969                      показывает Rich Presence
```

1. `YouTubeToDiscord.user.js` читает состояние плеера со страницы и отправляет его на `http://127.0.0.1:6969` каждые несколько секунд и при play / pause / перемотке.
2. `server.js` принимает данные и обновляет твой статус в Discord. К Discord он обращается только при реальных изменениях, чтобы не упираться в лимиты.

Ничего не уходит с твоего компьютера, кроме данных Rich Presence, которые и так показывает сам Discord.

## Требования

- Windows (скрипты запуска для Windows, а сам мост это обычный Node.js)
- **Десктопное приложение Discord**, запущенное (браузерная версия не подходит)
- [Node.js](https://nodejs.org/en/download) 18 или новее, добавленный в `PATH`
- Chrome или другой Chromium-браузер с расширением [Tampermonkey](https://www.tampermonkey.net)

## Установка

### 1. Создай приложение в Discord

1. Открой [Discord Developer Portal](https://discord.com/developers/applications) и нажми **New Application**.
2. Назови его **YouTube**. Это название будет в статусе: «Слушает YouTube».
3. Скопируй **Application ID** со страницы General Information.

### 2. Настрой и запусти мост

1. Склонируй или скачай этот репозиторий.
2. Открой `config.json` и замени `YOUR_APPLICATION_ID` на свой Application ID.
3. Запусти `start.bat`. При первом запуске зависимости установятся автоматически. Появится красная иконка в трее (она может быть под стрелкой «Показать скрытые значки»).

Чтобы запустить вручную и видеть логи:

```
npm install
npm start
```

### 3. Установи userscript

1. В Tampermonkey создай новый скрипт, вставь содержимое `YouTubeToDiscord.user.js` и сохрани.
2. Когда Tampermonkey спросит доступ к `127.0.0.1`, выбери **Always allow**.
3. В Chrome 138 и новее открой `chrome://extensions`, зайди в **Details** у Tampermonkey и включи **Allow User Scripts** (или включи режим разработчика). Перезагрузи вкладку YouTube.

### 4. Проверь настройки Discord

В **Настройки → Конфиденциальность активности** включи **Делиться обнаруженной активностью** и убедись, что твой статус не «Невидимый».

Открой любое видео на `youtube.com/watch?v=...` или трек на `music.youtube.com` и нажми play.

## Использование

- Запускай мост через `start.bat`. Останавливай через иконку в трее: правый клик → **Exit**.
- Чтобы запускать вместе с Windows, нажми `Win+R`, введи `shell:startup` и положи в открывшуюся папку ярлык на `start.bat`.
- Лог скрытого моста пишется в `log.txt` рядом со скриптами.

## Заметки и ограничения

- **Свои кнопки ты не увидишь.** Discord скрывает кнопки Rich Presence от владельца статуса, другие люди их видят. Для тебя работают кликабельные название, автор и картинки.
- В статусе максимум две кнопки, и подписи у них одинаковые для всех. Discord не сообщает приложению язык зрителя, поэтому подписи на английском.
- Поддерживается только десктопный клиент Discord с локальным IPC-подключением.
- Одновременно должна играть одна вкладка. Если вкладок несколько, побеждают последние данные.
- YouTube время от времени меняет вёрстку. Если пропали название, автор или аватарка, обнови селекторы в `YouTubeToDiscord.user.js` (вызовы `querySelector` в `getInfo`).
- На YouTube Music аватарки канала нет, поэтому маленькая картинка там не показывается.

## Решение проблем

| Проблема | Что проверить |
| --- | --- |
| Ничего не происходит | Запусти `npm start` и посмотри вывод. Должны быть строки «Listening on…» и «Connected to Discord as…». |
| «Discord not found» | Запусти десктопный Discord (не браузерный и не из Microsoft Store) и подожди несколько секунд. |
| В Tampermonkey нет скрипта на странице | Включи **Allow User Scripts** для Tampermonkey в `chrome://extensions` и перезагрузи вкладку. Открой страницу `watch?v=` (Shorts не поддерживаются). |
| Данные не доходят до моста | Открой в браузере `http://127.0.0.1:6969`, должно быть `ok`. Проверь, что Tampermonkey разрешено подключаться к `127.0.0.1`. |
| Нет иконки в трее | Посмотри `log.txt`. Антивирус может блокировать вспомогательный exe из `systray2`, проверь журнал защиты. Убедись, что `node -v` работает в новом терминале. Закрой старые процессы `node.exe` в диспетчере задач: второй экземпляр сразу завершается, если порт уже занят. |
| Статус не появляется | Проверь «Конфиденциальность активности» в Discord и что статус не «Невидимый». |
| Нет кнопок | Свои кнопки ты не видишь. Попроси друга посмотреть или проверь со второго аккаунта. |

## Структура проекта

```
config.json                      Application ID приложения Discord
server.js                        локальный мост: HTTP-сервер, Discord RPC, иконка в трее
YouTubeToDiscord.user.js      userscript для Tampermonkey
start.bat / start-hidden.vbs     скрытый запуск для Windows
icon.ico                         иконка в трее
```
